# 이지하게

귀찮은 사무 작업을 한 번에 끝내는 무료 자동화 도구 모음이에요.
설치 없이 내려받아 바로 쓰면 돼요.

## 도구

| 도구 | 하는 일 | 받기 |
|---|---|---|
| **메일 자동 발송** | 엑셀 명단 한 줄 → 메일 한 통. 사람마다 이름·금액 같은 내용과 첨부 파일을 바꿔서 내 지메일·네이버 계정으로 보내요. | [Releases](../../releases) |

## 받는 방법

1. 오른쪽 **Releases**에서 쓰려는 도구의 최신 버전을 열어요.
2. **Assets** 아래 `.zip` 파일을 내려받아요.
3. 압축을 풀고 폴더 안의 `.exe`를 실행해요.

- 폴더째 **바탕 화면이나 문서 폴더**에 두세요. `Program Files` 같은 곳에서는 기록을 저장하지 못해요.
- exe 옆의 폴더(`명단`, `첨부`, `기록` 등)는 지우지 말고 함께 두세요.

### "Windows의 PC 보호" 창이 뜨면

개인이 만든 무료 프로그램이라 처음 실행할 때 이 창이 나올 수 있어요.
**[추가 정보] → [실행]**을 누르면 돼요.

## 요구사항

- Windows 11
- 설치는 필요 없어요.

## 메일 자동 발송 사용 전에 알아두세요

- 개인 지메일은 **하루 500통**까지 보낼 수 있어요. 네이버도 계정마다 하루 발송 제한이 있어요. 넘으면 다음 날 **[안 보낸 사람만 이어서]**로 나머지를 보내요.
- 업무 메일을 수십~수백 명에게 보내는 용도예요. **광고·대량 발송용이 아니에요.**
- 비밀번호는 파일에 저장하지 않고 Windows 자격 증명 관리자에 보관해요.
- 지메일은 2단계 인증을 켠 뒤 [앱 비밀번호](https://myaccount.google.com/apppasswords)를 만들어 넣어요. 네이버는 메일 환경설정 → [POP3/IMAP 설정](https://mail.naver.com/option/imap)에서 'SMTP 사용'을 켜요.
